# nb ノート参照

`nbs` (fish 関数) を使って，現在の herdr ワークスペース名 (tmux 内ならセッション名，引数指定があればそのタイトル) に紐づく `nb` ノートを取得し，作業の前提・メモとして参照する．

## 手順

1. 以下のコマンドでノートのタイトルと本文を取得する (`<TITLE>` は引数指定があれば渡し，無ければ省略):

   ```bash
   fish --no-config -c 'source ~/.config/fish/functions/nbs.fish; nbs --name $argv; echo "---"; nbs --print $argv' -- <TITLE>
   ```

2. ノートの内容を要約し，把握したことを短く伝える．
3. ノートが見つからない場合はその旨を伝え，`nb list -n 100` で近いタイトルを探して候補を示す．
4. ノートの編集は頼まれたときだけ行い，`nb edit` (対話エディタ) ではなく `nb show --path <id>` で得たファイルパスを直接編集する．
